# Awesome Relocation Tech Jobs [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of job boards, handbooks, company directories, and practical resources for tech professionals seeking roles with **relocation packages** (and often visa support).

Relocation jobs combine three hard problems: finding an employer willing to move you, understanding the package, and navigating visas/housing. This list highlights the best discovery tools and the guides that explain what “good” relocation support looks like.

## What Relocation Packages Often Include

| Component | Examples |
| --- | --- |
| Travel | One-way flights for you (sometimes family) |
| Temporary housing | 2–8 weeks hotel / serviced apartment |
| Moving | Shipping allowance or lump-sum stipend |
| Immigration | Lawyer fees, permit filings (employer-side) |
| Settling-in | Language course, school search help, buddy |
| Clawbacks | Partial repayment if you leave early — read the contract |

Not every “relocation friendly” post includes all of the above. Ask for a **written breakdown** before accepting.

## Search Tips

1. Use relocation-native boards first ([Jaabz](https://jaabz.com/), Relocate.me) before keyword-hacking Indeed/LinkedIn.
2. Target **cities with clear skilled-immigration routes** (e.g. Berlin, Amsterdam, Stockholm, Toronto) if you need sponsorship too.
3. Ask recruiters early: *Who pays legal fees? Temporary housing length? Family included?*
4. Time offers around visa processing — a great package with a 6-month wait changes your plan.
5. Keep documents ready: degree scans, employment letters, police certificates where required.
